# `bb` math

A header only library aiming to reimplement and mimic GLM using C++20. Right now I focus on linear algebra topics and mathematics related with graphics programming.

## Requirements

- C++20 compatible compiler.

## Features

| Feature | Description                                           |
| ------- | ----------------------------------------------------- |
| Vector  | A list of numbers providing a direction and magnitude |

## Testing

[GoogleTest](https://github.com/google/googletest) is used for the tests.

```shell
# once built, run:
ctest --test-dir build
```
